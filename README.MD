## README ##
To run this repository:
1. Run the Startup.m script
2. Run the EvaluateController.m script.

# Folder Structure
- Models: Contains the physics engine
- Controllers: Contains any controller design related work
- CLF: Contains CLF functions

# Controller notes
The CoupledCLF_CBF.m function is the only active controller being used,
the other controllers were used for testing.

# Model Parameters
All model parameters can be found in the ModelParams.m function, this is 
the master source of truth for all configuration options.
